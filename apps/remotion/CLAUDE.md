# Remotion Video Studio — Development Guide

A reusable React + Remotion project for building animated explainer videos.
Each video is an independent **composition**; shared building blocks live in
`components/`, `lib/`, and `theme/`. Full docs: https://www.remotion.dev/docs/

## Commands

| Command         | What it does                                           |
| --------------- | ------------------------------------------------------ |
| `npm run dev`   | Open Remotion Studio (live preview at localhost:39573) |
| `npm run render -- <CompId> [file.mp4] [flags]` | Render → `out/<CompId>/` |
| `npm run still -- <CompId> [file.png] --frame=N` | Still → `out/<CompId>/` |
| `npm run lint`  | `tsc --noEmit` type check                              |
| `npm run upgrade` | Upgrade all Remotion packages in lockstep            |

Output is organized **per composition**: `out/<CompositionId>/<filename>`. Filename
defaults to `<CompId>.mp4` / `<CompId>.png` if omitted. Extra flags (e.g.
`--frame=30`, `--quality=90`) pass straight through to Remotion. The wrapper lives
in `scripts/remotion-out.mjs`; use `npm run render:raw` / `still:raw` to bypass it.

## Project Structure

```
src/
  index.ts                 registerRoot — entry point
  Root.tsx                 registers every <Composition>; add new videos here
  theme/index.ts           design tokens: colors, fonts, sizes, spacing
  lib/
    fonts.ts               Google Fonts loader (Montserrat, Cyrillic + Latin)
    animations.ts          reusable frame-driven helpers (fadeIn, slideIn, popIn…)
  components/              ALL reusable UI building blocks (import via ~/components)
    Background / Scene / AnimatedText / Card / MediaImage   layout & text primitives
    Cell / Timeline / BigNumber / PayoffGraph / EnergyBalance / TalkingHead   explainer blocks
    FlowStrip / MarketBars / Stamp / EUEmblem   light-mode blocks (white-bg inserts)
    index.ts                barrel export
  characters/             ALL drawable creatures & scenery (import via ~/characters)
    lottie/                 LottieCharacter wrapper (loads public/characters/lottie/*.json)
    svg/                    code-drawn: Frog, Fish, Worm, Rat, ButterflyVector, Critter, Deer, Hominid, Flora
    index.ts                barrel + LOTTIE_CHARACTERS / SVG_CHARACTERS catalogs
  compositions/           one folder per video — scenes/config/script ONLY, no shared code
    frendcoin/
      index.tsx             main component (chains scenes via TransitionSeries)
      config.ts             composition meta (id, fps, size, derived duration)
      script.ts             scene order, durations, narration text
      scenes/               one file per scene
```

## Core principle: everything reusable is shared

**No composition owns components or characters.** Anything you draw — a tree, the
sun, a water drop, a creature — goes into the shared library (`~/components` for
UI blocks, `~/characters` for anything drawable/creaturely), never inside a
single `compositions/<video>/` folder. Compositions only assemble scenes from
shared pieces. This keeps every asset reusable across future videos.

## Adding a New Video

1. `mkdir src/compositions/<name>/scenes`
2. Create `script.ts` (scenes + durations), `config.ts` (meta), `index.tsx` (assembles scenes).
3. Build scenes from shared `~/components`, `~/characters`, and `lib/animations.ts`. If you need a new drawable, add it to the shared library — not the composition.
4. Register it in `src/Root.tsx` with a `<Composition>`.

Use the `~/` path alias for imports (`~/components`, `~/theme`, `~/lib/...`).
Note: Remotion reserves `@` for its own internals, so this project uses `~`.

## Character Library (`~/characters`)

Reusable creatures, shared across videos. Two kinds:
- **Lottie** (`lottie/`): loaded via `<LottieCharacter name="amoeba" x y size />`
  from `public/characters/lottie/*.json` (downloaded clips, or ones generated by
  `scripts/gen-lottie-creatures.mjs`). **Registration is automatic:** the files on
  disk are the source of truth — `public/sync-characters.mjs` regenerates
  `lottie/catalog.generated.ts` (from which `LottieCharacterName` is derived), and
  it runs automatically before `dev`/`studio`/`render`/`still`. To add one: drop
  the `.json` in, done. Never hand-edit the catalog or the name type.
  `<LottieCharacter>` also supports `startFrame` (skip an intro), `freezeAtFrame`
  (stop on a frame), `grayscale`, `rotate`, `facing`.
- **SVG** (`svg/`): recognizable animals drawn in code. Shared `CreatureProps`
  (`x, y, size, facing, hurt, phase, moving`); `hurt` shows the victim state
  (✖ eyes, drained color, droop). All frame-driven and deterministic.
  - **Pencil-on-paper style** (`*Pencil` components, the macket look): bold
    graphite outline, faceted/angular forms, optional muted pastel, on warm
    paper. Shared system in `svg/_pencil.tsx` (`INK`, `PAPER`, `PASTEL`,
    `PencilDefs`, `Sketch`, `PaperBackground`); full guide + AI generation prompt
    + animation spec in **`svg/PENCIL_STYLE.md`**. Build new ones from `<Sketch>`
    + faceted `<polygon>`s. The flat-vector originals are kept alongside.

Preview them in isolation via the `CharacterLab` composition (Root → shows the
pencil `PencilGallery`) and the `PredationPencil` composition (pencil predators
meet prey, in motion, on paper). Repoint while iterating.

## Remotion Rules (must follow)

- **Determinism:** all code must be deterministic. No `Math.random()` — use
  `random('seed')`. No `Date.now()`. No `useState` for animation.
- **Frame-driven:** every motion derives from `useCurrentFrame()`. Inside a
  `Sequence`/`TransitionSeries.Sequence`, the frame resets to 0.
- **Animate with** `interpolate(frame, [inFrames], [outValues], { extrapolateLeft: 'clamp', extrapolateRight: 'clamp' })`
  or `spring({ fps, frame, config: { damping: 200 } })`. Prefer the helpers in
  `lib/animations.ts`.
- **Config via hooks:** read `fps`, `width`, `height`, `durationInFrames` from
  `useVideoConfig()`.
- **Assets:** put files in `public/`, reference with `staticFile('name.ext')`.

## Layout & Timing Primitives

- `<AbsoluteFill>` — stack full-frame layers.
- `<Sequence from={f} durationInFrames={n}>` — place content on the timeline.
- `<Series>` / `<TransitionSeries>` — chain scenes, with optional transitions
  (`@remotion/transitions`: `fade()`, `slide()`, `linearTiming(...)`).

## Media Components

- Video: `<OffthreadVideo>` (props `startFrom`, `endAt`, `volume` 0–1)
- Images: `<Img>` · GIFs: `<Gif>` from `@remotion/gif` · reusable `MediaImage` (fade + Ken Burns)
- Audio: `<Audio src={staticFile(...)} />` — automatically muxed into the MP4 on render

## Syncing to a Voiceover (plan-driven)

For VO-driven videos, a single `plan.ts` is the source of truth (see
`carnivores/plan.ts`). It exports `AUDIO`, `AUDIO_DURATION_SEC`, `FPS`, and
`PLAN` — one entry per scene with `{ id, title, description, narration, mode,
startSec }`, ordered by `startSec`. `TIMED_PLAN` derives each scene's
`fromFrame`/`durationInFrames` (a scene ends where the next begins; the last ends
at `AUDIO_DURATION_SEC`).

The composition (`carnivores/index.tsx`) then:

- puts one `<Audio src={staticFile(AUDIO)} />` at the top (drives the timeline);
- places each scene as an absolute `<Sequence from={fromFrame} durationInFrames=…>`
  (exact sync — no transition overlaps to shift timing);
- looks up the scene component in `SCENE_COMPONENTS[id]`; **if none exists, it
  renders `<ScenePlaceholder>`** showing the plan text. So an un-built beat is
  still on the timeline, described from the plan — fill it by adding the
  component and wiring it into the registry.

Get timestamps from a transcript (`transcription/*.srt`) rather than guessing
pauses. Keep `AUDIO_DURATION_SEC` ≥ the real length so the last line isn't clipped.

## Conventions

- Defaults: 30 fps, 1920×1080.
- Keep scenes presentational; keep timing/text in the composition's `plan.ts` (or `script.ts`).
- Re-skin all videos by editing `theme/index.ts` only. `colors` is the dark
  palette; `light` is the white-bg palette (EU-blue accent) for inserts that
  must blend with flat animated charts — see `eu-regulations` / `eu-manufacturers`.
